# محرك YIN للبحث في الأدبيات العلمية

**الاسم:** Youth Ink Network (YIN) — Research Engine  
**الإصدار البرمجي:** 0.4.0 — نسخة تطوير أولية (MVP)  
**اللغة:** واجهة عربية/إنجليزية، مع توثيق عربي وإنجليزي  
**الحالة:** جاهز للاختبار المحلي والتجهيز للنشر؛ لم يُثبت هذا المستودع وحده أن نشرًا سحابيًا قد تم.

> **تنبيه منهجي:** YIN أداة لاكتشاف الأدبيات وجمع بياناتها الوصفية وحفظ مسارات التشغيل وتصدير المراجع. ليست قاعدة بيانات شاملة، ولا تنفذ تلقائيًا مراجعة منهجية مكتملة أو تقييمًا موثوقًا لخطر التحيز. يجب التحقق بشريًا من كل مرجع وادعاء قبل الاستشهاد الأكاديمي.

## محتويات المشروع

- `app.py`: واجهة API مبنية بـ FastAPI.
- `engine.py`: البحث عبر OpenAlex، واسترجاع بيانات Crossref والتحقق من DOI وبناء تقرير أدلة.
- `storage.py`: تخزين SQLite وسجل العمليات والأحداث.
- `reference_export.py`: تصدير المراجع بصيغ APA7 التقريبية وBibTeX وRIS.
- `verification_layer.py`: تدقيق اختياري للادعاءات بمساعدة نموذج لغوي متوافق مع واجهة OpenAI؛ ليس مصنف NLI معتمدًا.
- `openscholar_adapter.py`: جسر اختياري إلى خدمة OpenScholar منفصلة؛ لا يتضمن تشغيل النموذج الكامل.
- `streamlit_app.py`: واجهة استخدام ثنائية اللغة.
- `tests/`: اختبارات آلية باستخدام pytest.
- `Dockerfile`: حاوية FastAPI.
- `Dockerfile.streamlit`: حاوية واجهة Streamlit.
- `render.yaml`: إعداد مقترح لخدمة API على Render مع قرص دائم.
- `.gitignore` و`.dockerignore`: استبعاد ملفات محلية وأسرار وقواعد بيانات من Git وبناء Docker.
- `.github/workflows/tests.yml`: تشغيل الاختبارات آليًا على GitHub Actions.
- `docs/`: أدلة الإعداد والاختبار والنشر وحدود الاستخدام الأكاديمي.

## المتطلبات

- Python 3.11 موصى به للتشغيل المحلي والحاويات.
- اتصال بالإنترنت لاستعلامات OpenAlex وCrossref.
- Git لرفع المشروع إلى GitHub.
- حسابات GitHub وRender، وحساب Streamlit Community Cloud إذا رغبت في استضافة الواجهة منفصلة.
- خدمة LLM أو OpenScholar متوافقة فقط إذا أردت تفعيل الوظائف الاختيارية المرتبطة بها.

## التشغيل المحلي

أنشئ بيئة افتراضية وثبّت الاعتماديات:

```bash
python -m venv .venv
```

في Linux/macOS:

```bash
source .venv/bin/activate
```

في Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

ثم:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pytest -q
uvicorn app:app --reload
```

افتح `http://127.0.0.1:8000/docs` لتجربة API. وفي نافذة طرفية أخرى شغّل:

```bash
streamlit run streamlit_app.py
```

تفتح الواجهة عادةً على `http://localhost:8501`. العنوان الافتراضي للـ API هو `http://127.0.0.1:8000` ويمكن تغييره بمتغير البيئة `YIN_API_URL`.

## متغيرات البيئة

| المتغير | الوظيفة | مطلوب دائمًا؟ |
|---|---|---|
| `YIN_DB_PATH` | مسار قاعدة SQLite | لا؛ يوجد مسار افتراضي محلي |
| `YIN_API_URL` | عنوان FastAPI الذي تتصل به واجهة Streamlit | لا محليًا؛ مطلوب ضبطه عند فصل الواجهة عن API |
| `YIN_LLM_BASE_URL` | عنوان واجهة LLM متوافقة | لا؛ للتدقيق الاختياري |
| `YIN_LLM_API_KEY` | مفتاح خدمة LLM | لا؛ للتدقيق الاختياري، ويجب حفظه سرًا |
| `YIN_LLM_MODEL` | اسم النموذج | لا؛ للتدقيق الاختياري |
| `YIN_LLM_TIMEOUT` | مهلة طلب LLM بالثواني | لا؛ الافتراضي 60 |
| `YIN_OPENSCHOLAR_BRIDGE_URL` | عنوان خدمة OpenScholar خارجية | لا؛ للتوليف الاختياري |

انسخ `.env.example` إلى `.env` عند الحاجة للتوثيق المحلي، لكن التطبيق لا يحمّل ملف `.env` تلقائيًا. عيّن المتغيرات في بيئتك أو استخدم مدير أسرار الاستضافة. لا ترفع `.env` أو المفاتيح إلى GitHub.

## مسارات API الرئيسية

- `GET /health` — حالة الخدمة وإعدادات عامة غير سرية.
- `POST /search` — بحث وحفظ سجل تشغيل.
- `POST /review` — تقرير أدلة، مع توليف وتدقيق وتصدير اختياري.
- `POST /verify-doi?doi=...` — فحص سجل DOI لدى Crossref؛ لا يثبت صحة نتائج البحث.
- `POST /export/bibtex` أو `/export/ris` أو `/export/apa7` — تصدير مراجع.
- `GET /runs` — قائمة عمليات سابقة.
- `GET /runs/{run_id}` — تفاصيل عملية محفوظة.
- `GET /docs` — توثيق تفاعلي.

## بيانات البحث والخصوصية

تُحفظ سجلات التشغيل محليًا في SQLite. لا ترفع قواعد البيانات إلى المستودع العام؛ فقد تتضمن استعلامات أو مخرجات بحث. عند استخدام خدمة LLM أو جسر خارجي، راجع سياسة بيانات ذلك المزود قبل إرسال أي بيانات حساسة. لا ترسل بيانات شخصية أو سرية ضمن استعلامات البحث.
