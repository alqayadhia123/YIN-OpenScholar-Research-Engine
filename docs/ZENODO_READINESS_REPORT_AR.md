# تقرير جاهزية أرشفة YIN في Zenodo

**المستودع:** https://github.com/alqayadhia123/YIN-OpenScholar-Research-Engine  
**فرع المراجعة:** `zenodo-readiness/mit-metadata`  
**النسخة المعلنة في README:** 0.4.0 (MVP)  
**الحالة:** مراجعة وتجهيز أولي؛ غير معتمد للإيداع أو إصدار DOI.

## ما أُعدّ على فرع المراجعة

- `LICENSE`: نص MIT للشفرة الأصلية للمشروع، بناءً على اختيار مالك المشروع.
- `CITATION.cff`: بيانات الاستشهاد، مع اسم المؤلف ومعرّف ORCID المقدم.
- `.zenodo.json`: بيانات وصفية أولية مقترحة لإيداع برمجي.
- تحديث README العربي والإنجليزي لشرح الترخيص وحدود الأرشفة.

## ما لم يحدث

- لم يُنشأ GitHub Release.
- لم يُنشأ Git Tag.
- لم يُفعّل ربط GitHub مع Zenodo ولم يُفعّل أرشيف المستودع.
- لم يُرفع أي إصدار إلى Zenodo.
- لم يصدر DOI.
- لم تُدمج التغييرات في الفرع الرئيسي `main`.

## بوابة ما قبل الإيداع — ما زال مطلوباً

1. مراجعة حقوق ملكية كل ملف أصلي وتأكيد أن مالك المشروع مخول بمنح MIT.
2. جرد تراخيص التبعيات المباشرة وغير المباشرة، ومراجعة تراخيص الخدمات ومجموعات البيانات الخارجية.
3. فحص المستودع بحثاً عن الأسرار والبيانات الشخصية وقواعد البيانات والملفات غير المناسبة للأرشفة.
4. تشغيل الاختبارات في بيئة نظيفة وتسجيل النتائج الفعلية؛ لا يُعد وجود ملفات الاختبار دليلاً على نجاحها.
5. التحقق من صحة `CITATION.cff` و`.zenodo.json` باستخدام أدوات تحقق مناسبة.
6. مراجعة الاسم والوصف والإصدار والمؤلف وORCID والكلمات المفتاحية وحقوق النشر.
7. مراجعة محتويات الأرشيف النهائية قبل أي رفع.
8. الحصول على موافقة صريحة منفصلة قبل إنشاء Release أو Tag أو بدء الإيداع.

## ملاحظات منهجية

- إصدار البرنامج `0.4.0` الوارد في README هو بيان الإصدار الحالي للمشروع، وليس دليلاً على إصدار أرشيفي منشور.
- ترخيص MIT للمشروع لا يمنح حقوقاً على مكونات الأطراف الثالثة.
- بيانات Zenodo الحالية أولية ولا تتضمن DOI.
- لا يُوصف المشروع بأنه مراجعة منهجية مكتملة أو أداة تحقق علمي آلي؛ تبقى مراجعة الأدلة والمراجع والادعاءات مسؤولية بشرية.
